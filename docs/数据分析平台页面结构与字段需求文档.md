> 目的：供数据分析师了解各页面所需的数据指标与字段，规划日志埋点方案。
> 最后更新：2026-04-20

---

| 序号 | 页面标签 | 路由 ID | 说明 |
|------|----------|---------|------|

| 17 | 卡牌分析 | `card` | 卡牌使用率、强度分布、培养成本 |

## 通用筛选条件

各分析页面均支持以下筛选维度（实际筛选项因页面而异）：

| 筛选项 | 说明 | 备注 |
|--------|------|------|
| 开始时间 | 日期选择器 | 默认近7/14/30天 |
| 结束时间 | 日期选择器 | 默认为当天 |
| 服务器 | 全部 / 英文地区 / 韩国 / 港澳台 | 地区代码：en / kr / tw |
| 终端 | 全部 / iOS / Android / 安卓官方包 / PC官方包 / Steam | 部分页面支持 |
| 有效/去黑产/去水 | 7种组合选项 | 有效 / 去黑产 / 去水 及两两/三者组合 |

## 一、KPI 仪表盘 (`overview`)

### 页面结构
- 年度/新增统计卡片
- 活跃用户趋势折线图
- 活跃用户趋势-按新增时间堆积面积图
- 收入趋势面积图

### 数据字段需求

#### 1. 活跃用户趋势（折线图）

| 字段名 | 中文名 | 类型 | 说明 |
|--------|--------|------|------|
| `date` | 日期 | string | 格式：YYYY-MM-DD |
| `dau` | DAU（活跃账号） | integer | 当日活跃账号数 |
| `newUsers` | 新增用户 | integer | 当日新增账号数 |
| `continuousActive` | 持续活跃用户 | integer | 当日活跃的老用户数 |
| `returningUsers` | 回流用户 | integer | 当日回流的账号数 |

#### 2. 活跃用户趋势-按新增时间（堆积面积图）

| 字段名 | 中文名 | 类型 | 说明 |
|--------|--------|------|------|
| `month` | 月份 | string | 格式：1月、2月... |
| `newUsersYYYY` | 年新增用户 | integer | 按新增时间分组的活跃用户数 |

#### 3. 收入趋势（面积图）

| 字段名 | 中文名 | 类型 | 说明 |
|--------|--------|------|------|
| `date` | 日期 | string | 格式：YYYY-MM-DD |
| `revenue` | 收入 | integer | 当日总收入（单位：分或元） |

## 二、实时数据 (`realtime`)

### 页面结构
- KPI 卡片（当前在线人数、今日实时活跃账号、今日实时新增账号、今日实时收入）
- 分小时在线趋势图
- 分小时新增 & 活跃趋势折线图
- 日内小时明细表

### 数据字段需求

#### 1. KPI 卡片

| 字段名 | 中文名 | 类型 | 说明 |
|--------|--------|------|------|
| `online` | 当前在线人数（账号） | integer | 实时在线账号数 |
| `onlineChange` | 较昨日变化 | float | 百分比变化 |
| `active` | 今日实时活跃账号 | integer | 当日累计活跃账号 |
| `activeRatio` | 活跃/新增倍数 | float | active / newUsers |
| `newUsers` | 今日实时新增账号 | integer | 当日新增账号 |
| `newEstimate` | 预计全天新增 | integer | 根据当前速率预估 |
| `revenue` | 今日实时收入 | integer | 当日累计收入 |
| `payingUsers` | 付费人数 | integer | 当日付费人数 |
| `arppu` | ARPPU | float | revenue / payingUsers |

#### 2. 分小时在线趋势（条形图）

| 字段名 | 中文名 | 类型 | 说明 |
|--------|--------|------|------|
| `hour` | 小时 | string | 格式：HH:00，0-23 |
| `value` | 在线人数 | integer | 当小时在线峰值账号数 |

#### 3. 分小时新增 & 活跃趋势（折线图）

| 字段名 | 中文名 | 类型 | 说明 |
|--------|--------|------|------|
| `hour` | 小时 | string | HH:00 |
| `active` | 活跃账号数 | integer | 当小时活跃账号数 |
| `activeDevice` | 活跃设备数 | integer | 当小时活跃设备数 |
| `new` | 新增账号数 | integer | 当小时新增账号数 |
| `revenue` | 每日总收入 | integer | 当小时收入（累计到该小时） |
| `paying` | 付费账号数 | integer | 当小时付费账号数（累计） |
| `payRate` | 付费率 | float | 百分比 |
| `arpu` | ARPU | float | 人均收入 |
| `arppu` | ARPPU | float | 付费用户人均收入 |
| `payActive` | 付费活跃账号数 | integer | 当小时有付费行为的活跃账号 |
| `newPayUser` | 新增付费用户数 | integer | 当小时首次付费的账号数 |
| `firstPayUser` | 首次付费用户数 | integer | 当小时首次完成付费的账号数 |

## 六、地区对比 (`region`)

### 页面结构
- 7个图表，均按地区（英文地区/韩国/港澳台）分组展示：
  1. DAU对比（堆积面积图）
  2. MAU对比（柱状图）
  3. 收入对比（堆积面积图）
  4. ARPU对比（折线图）
  5. 新增对比（折线图）
  6. ARPPU对比（折线图）
  7. 付费率对比（折线图）
